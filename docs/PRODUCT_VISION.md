# Social Media Harness 产品目标

## 目标

把持续拍摄的真实生产、产品与现场素材，转化为可追溯、可评审、可返工、可归档的社交媒体内容包，并尽量减少所有者在普通制作环节中的人工干预。

系统首先服务于 Instagram Reels 和 YouTube Shorts，内容定位以真实展示、纪实表达和视觉品质为主，不把平台内容自动变成销售或发布渠道。

## 目标形态

最终形态由三部分组成：

1. 账户级个人 Skill：让任何 Codex 会话能够识别并启动本流程。
2. 本地 Python 工作流引擎：执行状态管理、模型路由、评审循环、ComfyUI、FFmpeg、归档和恢复。
3. 每个业务项目独立的数据目录：保存品牌规则、素材、Campaign、评审、决定和发布包。

Skill 是入口，不是事实数据库；项目文件与结构化配置才是长期记忆。

## 成功标准

- 每一阶段都有明确输入、输出、状态和验收证据。
- Claude 与 MiniMax 在正式评审时获得该阶段完整且适合其模态的证据，而非无代表性的少量片段。
- Codex可以自动处理有证据、低风险且不冲突的普通建议。
- 只有方向选择、事实或隐私不确定、评审冲突、返工超限和最终发布需要所有者介入。
- ComfyUI和MiniMax生成能力成为受控执行后端；生成内容不会被默认为真实现场证据。
- 新对话能够仅依赖持久化文件恢复当前状态，不依赖完整聊天历史。

## 非目标与边界

- 不自动发布到任何社交平台。
- 不覆盖或改写原始素材。
- 不在仓库、Skill或日志中保存API Key。
- 不把旧模型意见自动视为现行规则。
- 不让生成媒体在没有披露和评审的情况下替代真实素材。
